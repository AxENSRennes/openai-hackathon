# Choose the photo-to-character flow

Type: Grilling (human decision)
Status: Resolved

## Question

How should a photo become the cameo character used in Coffee Run? Decide who provides the photo, when the game creates or selects the character, what visual resemblance to preserve, and what to do when no suitable photo is available.

## Resolution

The host can submit a photo during the race. Create the cameo character from that photo for a recognizable, stylized likeness. If there is no suitable photo or the live character is not ready in time, let the host choose a pre-captured cameo character.
